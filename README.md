# 專案與人力管理系統

## 啟動
1. 編輯 `js/config.js`,填入 Supabase 的 Project URL 與 anon key。
2. Supabase → Authentication → Users → Add user,建立登入帳號(勾選 Auto Confirm)。
3. (可選)在 SQL Editor 執行 `seed.sql` 取得測試資料。
4. 在本資料夾開終端機:`python -m http.server 8000`
5. 瀏覽器開 http://localhost:8000

## 階段判斷規則
見 `js/utils/phase.js` 檔頭註解;定義不同時只需修改該函式。

## 專案總覽(projects.html)
- 可用「日 / 週 / 旬 / 月 / 季 / 年」縮放。
- 縮放比例定義在 `js/components/timeline.js` 的 `ZOOMS`(每天幾個 px),要新增比例只需加一行。
- 時間軸長條 = `start_date ~ end_date`,只有外框(顏色依專案狀態)。
- 每個里程碑依 `target_date` 標在長條上:日期在上方、名稱(`milestones.phase`,自由文字,如 KO、POC、EVT1)在下方;太擠時自動錯開並用細線連回。
- 專案長條內以實心長條顯示人力配置(`allocations`):每位成員一列,長條上只在最左邊的一段顯示姓名(投入 % 與日期在滑鼠停留的提示中),每人固定一色、顏色越深投入越高;同一人不同期間排在同一列。右上角「顯示人力配置」是三態 checkbox(全部顯示 / 全部不顯示 / 部分顯示〔橫線〕),點它會讓所有專案一起顯示或隱藏;也可以在某個專案右邊的時間軸區域雙擊,單獨切換該專案(個別設定不會記憶,重新整理後依 checkbox 的記憶值)。
- 狀態與篩選、搜尋在兩種檢視間共用;所選檢視與縮放會記在瀏覽器裡。

## 人力資源總覽(resources.html)
橫軸日期與專案總覽相同(日 / 週 / 旬 / 月 / 季 / 年縮放),縱軸為每位成員(依職務、姓名排序,沒有配置的成員也會列出)。
- 每筆配置一條實心長條;同一專案只在最左邊那段顯示「機種 投入%」,其餘各段只顯示投入%;每個專案固定一色,顏色越深投入越高;滑鼠停留可看客戶、機種、百分比與日期。
- 右上角「顯示專案配置」是三態 checkbox(全部顯示 / 全部不顯示 / 部分顯示〔橫線〕),點它會讓所有成員一起切換;也可以在某位成員右邊的配置區雙擊,單獨切換該成員(個別設定不會記憶)。勾選=逐專案配置長條;取消=只顯示各時期投入專案工作的百分比加總(長條上不顯示數字,滑鼠停留才以多行顯示「合計 % : 期間」與各專案的投入 %;0% 的時段不畫長條、不顯示數字,維持空白;顏色越深加總越高,深淺範圍為 0% ~ 200%,超過 200% 以最深色顯示;範圍上限是 `js/utils/constants.js` 的 `SUM_COLOR_MAX`)。
- 同一成員的同一個專案,所有配置一定顯示在同一條;同時投入多個專案時不同專案上下堆疊;時間不重疊的不同專案(如前後銜接)共用同一列。
- 搜尋(姓名、工號)篩選;另有依職務(`members.role`)篩選的按鈕,但只有成員的職務分成兩類以上時才會顯示(職務都沒填或全都一樣時,按鈕點了結果相同,所以不顯示)。
- 日期軸、縮放、顯示範圍等共用邏輯在 `js/components/timeAxis.js`,兩個頁面共用。

## 「今天」方向箭頭
專案總覽與人力資源總覽的甘特圖,若目前看到的畫面範圍不包含今天,日期列最左邊(今天在左)或最右邊(今天在右)會顯示紅色的「◀ 今天」/「今天 ▶」箭頭,點擊可跳到今天。邏輯在 `js/components/todayHint.js`,樣式在 `css/timeline.css` 最後的 `.tl__today-arrow`。

## 成員提示(分機與 Email)
人力資源總覽中,滑鼠停在成員欄上,瀏覽器內建的提示會顯示兩行:分機(`members.extension`)與 Email(`members.email`),未填顯示「未設定」。實作在 `js/components/resourceTimeline.js` 的 `memberHintTitle()`(以 `title` 屬性實現)。

## 配置長條的名稱標示
同一組(人力資源總覽:同一成員的同一專案;專案總覽:同一成員)的多段配置長條,只在「目前看得到的最左邊、且放得下名稱的那一段」標示名稱。橫向捲動、縮放時會即時重新決定,所以最左邊那段被捲出畫面後,名稱會改標在右邊的下一段。邏輯在 `js/components/barLabels.js`,兩個頁面共用。

## 專案狀態與 Pending 篩選
專案總覽的篩選為 checkbox,顯示「階段 : 數量」(BD / NPI / MP / Pending,四類各自的專案數,加起來等於專案總數)。每個專案只屬於一類(暫緩中的歸 Pending,其餘依狀態),勾選哪一類就顯示哪一類;勾選變動時下方結果立刻更新。預設勾選的項目在 `js/utils/constants.js` 的 `DEFAULT_FILTERS`(預設 BD、NPI、MP)。舊資料若 `status` 仍是 `'Pending'` 也會被視為暫緩。

## 日期尺度(日 / 週 / 旬 / 月 / 季 / 年)
專案總覽與人力資源總覽的時間軸共用同一套日期尺度,由細到粗:
- **日**:每格 1 天;**週**:每格 1 週(週一到週日);**旬**:每格 1 旬(上旬 1~10 日、中旬 11~20 日、下旬 21 日~月底);**月**、**季**(1~3、4~6、7~9、10~12 月)、**年**。
- 日、週、旬的日期列分兩層:上層顯示年月(捲動時文字會黏在可視範圍左側),下層顯示日 / 週 / 旬。
- **Ctrl + 滑鼠滾輪**(在時間軸上)可切換尺度:往上滾 = 放大(往「日」),往下滾 = 縮小(往「年」);滑鼠指著的日期縮放後會留在原位。邏輯在 `js/components/wheelZoom.js`。
- **休假日標示**:日、週、旬三個尺度會標示休假日——週六、週日自動標示,整欄淡灰底色貫穿所有列(日尺度另外把日期改成紅字);連續的休假日(週六日、春節連假等)合併成一塊。月、季、年預設不標示(一天只有 6 / 2.5 / 不到 1 個像素,週末會變成密集條紋),想標示的話,把 `'month'`、`'quarter'`、`'year'` 加進 `js/utils/constants.js` 的 `HOLIDAY_SHADE_UNITS` 即可。平日的國定假日 / 補假放在同一檔案的 `HOLIDAYS`(已預填 2026、2027 年政府行政機關辦公日曆,總天數與官方公布的 120 / 121 天相符);補班日放在 `MAKEUP_WORKDAYS`。每年新的辦公日曆公布後,請在 `HOLIDAYS` 補上新的一年。假日名稱只在日尺度的日期提示中顯示。
- 各尺度每天佔幾個像素在 `js/components/timeAxis.js` 的 `ZOOMS`。

## 縮放時保持畫面位置
縮放(日期尺度按鈕或 Ctrl + 滾輪)後,水平保持滑鼠指著(按鈕縮放則是畫面中央)的日期,垂直保持滑鼠指著(按鈕縮放則是畫面中央)的那一列資料,不會跳回最上面。垂直是記「第幾列 + 列內位置」而不是捲動距離,因為不同尺度下每一列的高度可能不同。邏輯在 `js/components/scrollAnchor.js`。篩選、搜尋改變時列會變動,垂直位置維持回到最上面。

## 左側名稱欄(「專案」/「成員」)的標題與寬度
- 標題格的文字水平、垂直都置中。
- 欄寬可以用滑鼠拖曳調整:拖曳標題格右緣的把手(游標會變成 ↔,滑鼠移上去會出現一條線);**雙擊**把手還原預設寬度(200px);把手取得焦點(Tab)後可用 ← → 微調,Shift 加大幅度。範圍 120px ~ 600px(視窗很窄時會保留至少 240px 給日期軌道)。
- 專案總覽與人力資源總覽的欄寬各自獨立,並記在瀏覽器裡(重新整理仍保留)。預設寬度與下限在 `js/components/timeAxis.js` 的 `LABEL_W`、`MIN_LABEL_W`;拖曳邏輯在 `js/components/columnResize.js`。
