# 專案與人力管理系統

## 啟動
1. 編輯 `js/config.js`,填入 Supabase 的 Project URL 與 anon key。
2. Supabase → Authentication → Users → Add user,建立登入帳號(勾選 Auto Confirm)。
3. (可選)在 SQL Editor 執行 `seed.sql` 取得測試資料。
4. 在本資料夾開終端機:`python -m http.server 8000`
5. 瀏覽器開 http://localhost:8000

## 階段判斷規則
見 `js/utils/phase.js` 檔頭註解;定義不同時只需修改該函式。

## 專案總覽(projects.html)
- 可用「日 / 週 / 旬 / 月 / 季 / 年」縮放。
- 縮放比例定義在 `js/components/timeline.js` 的 `ZOOMS`(每天幾個 px),要新增比例只需加一行。
- 時間軸長條 = `start_date ~ end_date`,只有外框(顏色依專案狀態)。
- 每個里程碑依 `target_date` 標在長條上:日期在上方、名稱(`milestones.phase`,自由文字,如 KO、POC、EVT1)在下方;太擠時自動錯開並用細線連回。
- 專案長條內以實心長條顯示人力配置(`allocations`):每位成員一列,長條上只在最左邊的一段顯示姓名(投入 % 與日期在滑鼠停留的提示中),每人固定一色、顏色越深投入越高;同一人不同期間排在同一列。右上角「顯示人力配置」是三態 checkbox(全部顯示 / 全部不顯示 / 部分顯示〔橫線〕),點它會讓所有專案一起顯示或隱藏;也可以在某個專案右邊的時間軸區域雙擊,單獨切換該專案(個別設定不會記憶,重新整理後依 checkbox 的記憶值)。
- 狀態與篩選、搜尋在兩種檢視間共用;所選檢視與縮放會記在瀏覽器裡。

## 人力資源總覽(resources.html)
橫軸日期與專案總覽相同(日 / 週 / 旬 / 月 / 季 / 年縮放),縱軸為每位成員(依職務、姓名排序,沒有配置的成員也會列出)。
- 每筆配置一條實心長條;同一專案只在最左邊那段顯示「機種 投入%」,其餘各段只顯示投入%;每個專案固定一色,顏色越深投入越高;滑鼠停留可看客戶、機種、百分比與日期。
- 右上角「顯示專案配置」是三態 checkbox(全部顯示 / 全部不顯示 / 部分顯示〔橫線〕),點它會讓所有成員一起切換;也可以在某位成員右邊的配置區雙擊,單獨切換該成員(個別設定不會記憶)。勾選=逐專案配置長條;取消=只顯示各時期投入專案工作的百分比加總(長條上不顯示數字,滑鼠停留才以多行顯示「合計 % : 期間」與各專案的投入 %;0% 的時段不畫長條、不顯示數字,維持空白;顏色越深加總越高,深淺範圍為 0% ~ 200%,超過 200% 以最深色顯示;範圍上限是 `js/utils/constants.js` 的 `SUM_COLOR_MAX`)。
- 同一成員的同一個專案,所有配置一定顯示在同一條;同時投入多個專案時不同專案上下堆疊;時間不重疊的不同專案(如前後銜接)共用同一列。
- 搜尋(姓名、工號)篩選;另有依職務(`members.role`)篩選的按鈕,但只有成員的職務分成兩類以上時才會顯示(職務都沒填或全都一樣時,按鈕點了結果相同,所以不顯示)。
- 日期軸、縮放、顯示範圍等共用邏輯在 `js/components/timeAxis.js`,兩個頁面共用。

## 「今天」方向箭頭
專案總覽與人力資源總覽的甘特圖,若目前看到的畫面範圍不包含今天,日期列最左邊(今天在左)或最右邊(今天在右)會顯示紅色的「◀ 今天」/「今天 ▶」箭頭,點擊可跳到今天。邏輯在 `js/components/todayHint.js`,樣式在 `css/timeline.css` 最後的 `.tl__today-arrow`。

## 成員提示(分機與 Email)
人力資源總覽中,滑鼠停在成員欄上,瀏覽器內建的提示會顯示兩行:分機(`members.extension`)與 Email(`members.email`),未填顯示「未設定」。實作在 `js/components/resourceTimeline.js` 的 `memberHintTitle()`(以 `title` 屬性實現)。

## 配置長條的名稱標示
同一組(人力資源總覽:同一成員的同一專案;專案總覽:同一成員)的多段配置長條,只在「目前看得到的最左邊、且放得下名稱的那一段」標示名稱。橫向捲動、縮放時會即時重新決定,所以最左邊那段被捲出畫面後,名稱會改標在右邊的下一段。邏輯在 `js/components/barLabels.js`,兩個頁面共用。

## 專案狀態與篩選
`projects.status` 是唯一的狀態欄位,值為 BD、NPI、MP、Pending(暫緩)。請參考 `js/utils/constants.js` 的 `STATUS_ORDER` 。
專案總覽的篩選為 checkbox,顯示「狀態 : 數量」(各狀態的專案數,加起來等於專案總數),勾選哪一種就顯示哪一種;勾選變動時下方結果立刻更新。預設勾選的項目在 `js/utils/constants.js` 的 `DEFAULT_FILTERS`(預設 BD、NPI、MP)。Pending 的長條為灰色虛線,EOL 為深紅色外框。

## 新增 / 編輯 / 刪除專案
- 右上角「＋ 新增專案」開啟對話框:客戶、機種(必填)、專案狀態、開始 / 結束日期、備註,以及可增減的里程碑清單(階段、目標日期、備註)。
- 編輯:滑鼠移到專案名稱欄,右上角會出現「⋮」按鈕(觸控裝置一律顯示),展開選單選「✎ 編輯專案」;或在專案名稱欄雙擊。
- 刪除:在編輯對話框左下角按「刪除專案」,再於確認畫面按「確認刪除」。會一併刪除該專案的里程碑與人力配置,無法復原。
- 人力配置(allocations)不在這個對話框內維護。儲存後會重新載入並保持目前的水平位置;剛儲存的專案若其狀態沒被勾選,會自動勾上。
- **權限**:只有管理員能用以上功能。身份讀自登入帳號的 `app_metadata.role`(raw_app_meta_data),沒有才讀 `user_metadata.role`(raw_user_meta_data),都沒有就是 viewer(`js/auth.js` 的 `getRole` / `isAdmin`);兩個頁面右上角的 email 旁會顯示身份,例如 `name@example.com (admin)`。viewer 看不到「新增專案」與名稱欄的「⋮」按鈕,雙擊專案名稱也不會開啟。資料庫端的寫入限制(RLS)與設定方式請看 `roles.sql`(RLS 只認 app_metadata,原因寫在檔案裡);改完角色後該帳號要重新登入。
- 程式:`js/components/projectDialog.js`、`js/api/projects.js`(createProject / updateProject / deleteProject)、`css/dialog.css`。

## 專案排序
搜尋列的「排序」下拉選單(會記住上次的選擇,預設開始日期),旁邊的下拉選單可選「遞增 / 遞減」(預設遞增;遞減時所有排序鍵一起反向),日期空白的專案不論遞增遞減都排最後:
- 客戶機種:customer → model
- 專案狀態:status(依 BD、NPI、MP、EOL、Pending 的順序,即 `STATUS_ORDER`)→ 客戶機種
- 開始日期:start_date → end_date → 客戶機種
- 結束日期:end_date → start_date → 客戶機種
邏輯在 `js/utils/sort.js`。

## 新增 / 編輯 / 刪除成員(僅限管理員)
- 右上角「＋ 新增成員」開啟對話框:姓名(必填)、職務(可從現有職務挑選或自填)、工號、分機、Email、職級、職稱。Email 與工號不能與其他成員重複。
- 編輯:滑鼠移到成員名稱欄,右上角會出現「⋮」按鈕(觸控裝置一律顯示),展開選單選「✎ 編輯成員」;或在成員名稱欄雙擊。
- 刪除:在編輯對話框左下角按「刪除成員」,再於確認畫面按「確認刪除」。會一併刪除該成員的人力配置,無法復原。人力配置本身不在這個對話框內維護。
- 權限與專案相同:只有管理員看得到這些功能,資料庫端的寫入限制(members 的 RLS)在 `roles.sql`(需要重新執行)。
- 程式:`js/components/memberDialog.js`、`js/api/members.js`(createMember / updateMember / deleteMember)、`css/dialog.css`。

## 新增 / 編輯 / 刪除專案成員配置(僅限管理員)
專案總覽與人力資源總覽都能維護配置(`allocations`:專案、成員、開始 / 結束日期、投入 %),共用同一個對話框(`js/components/allocationDialog.js`、`js/api/allocations.js`)。
- **編輯里程碑視窗**:雙擊菱形 → 跳出「編輯里程碑」視窗(名稱、日期、備註,樣式與新增視窗相同,只差標題與按鈕),按「儲存」才寫資料庫。
- **新增**:滑鼠移到專案(或成員)名稱欄,按右上角「⋮」,選「＋ 新增成員配置」(成員那一列為「＋ 新增專案配置」)。從專案進來時專案固定、選成員;從成員進來時成員固定、選專案。新增時換專案會自動帶入該專案的開始 / 結束日期(日期還沒手動改過才會)。
- **編輯 / 刪除**:雙擊配置長條,在對話框修改;左下角「刪除配置」會先二次確認。(人力資源總覽取消「顯示專案配置」時是加總視圖,沒有個別長條可雙擊。)
- **投入比例**:0~100%,滑桿與數字連動。對話框下方即時提示「該成員在這段期間其他專案最高同時投入 X%,加上本筆後最高 Y%」,超過 `LOAD_THRESHOLDS.high` 時以警示色提醒(只提醒,不阻擋儲存)。
- 儲存後若該專案 / 成員正隱藏配置,會自動改成顯示。管理員雙擊長條是「編輯配置」、不再切換顯示;要切換請在長條旁的空白處雙擊(viewer 沒有編輯功能,雙擊哪裡都是切換)。
- 權限同前:只有管理員看得到,資料庫端的 allocations 寫入限制在 `roles.sql`(需要重新執行)。

## 里程碑直接在時間軸上編輯(專案總覽,僅限管理員)
- **改名稱**:雙擊里程碑名稱(KO、EVT…),就地出現輸入框,下方固定列出全部標準階段 KO、POC、EVT、DVT、PVT、MP 供點選(也可自行輸入);Enter 確認、Esc 取消。
- **改日期**:雙擊里程碑日期,就地出現日期欄。
- **拖曳**:單擊菱形 → 變成琥珀色(選取中,游標變成左右箭頭),此時可左右拖曳,以天為單位,可拖很多次。拖曳過程只改畫面,不寫資料庫;調整過日期後,菱形旁邊會出現「確定 / 取消」:按「確定」才寫入資料庫,按「取消」或點其他任何地方都視為放棄修改(日期退回原本的)。日期尚未確定就關頁會先提醒。
- **新增**:專案長條內沒有顯示人力配置時(例如已取消該專案的人力配置顯示),在長條內的空白處雙擊 → 在滑鼠所在日期新增里程碑(輸入名稱與備註〔對應 note 欄位,選填〕,下拉建議只有標準階段 KO、POC、EVT、DVT、PVT、MP,也可自行輸入;日期可再調整)。長條內正顯示人力配置時,雙擊空白處仍是切換顯示。
- 在里程碑上雙擊不會切換人力配置顯示。viewer 沒有這些功能。刪除里程碑請用專案的編輯對話框。程式:`js/components/milestoneEditor.js`、`js/components/inlineEdit.js`、`js/api/milestones.js`。

## 人力配置長條直接在時間軸上編輯(兩個總覽頁,僅限管理員)
- **選取與拖曳(兩個總覽頁都開啟,各頁開關見 `js/utils/constants.js` 的 `ALLOC_EDGE_DRAG`)**:點一下配置長條 → 外框變成琥珀色(選取中),左右邊界可以拖曳。游標在邊界上變成左右箭頭,同時在邊界上方顯示該邊界的日期(左邊界 = 開始日期、右邊界 = 結束日期)。拖左邊界只改開始日期(結束日期不動),拖右邊界只改結束日期(開始日期不動),以天為單位,拖曳中上方日期即時跟著變,可拖很多次。拖曳過程只改畫面,不寫資料庫;調整過日期後,長條旁邊會出現「確定 / 取消」:按「確定」才寫入資料庫,按「取消」或點其他任何地方都視為放棄修改(外框變回原樣,日期退回原本的)。日期尚未確定就關頁會先提醒。程式:`js/components/confirmBar.js`(確定 / 取消按鈕列,里程碑也共用)。
- **編輯 / 刪除**:雙擊配置長條 → 開啟編輯視窗(與「⋮」選單的新增配置同一個視窗)。
- **新增**:顯示人力配置時,雙擊「空白處」→ 開啟新增視窗,開始日期帶入滑鼠所在的日期。專案總覽的空白處是專案長條內沒被配置長條蓋住的地方,人力資源總覽的空白處是成員那一列沒有長條的地方。
- 管理員在這些地方雙擊不再切換顯示方式,所以名稱欄「⋮」選單多了一項「隱藏 / 顯示人力配置」(人力資源總覽為「只顯示加總 / 顯示專案配置」);專案總覽長條外的軌道區域雙擊仍可切換。viewer 沒有編輯功能,雙擊一律是切換。
- 程式:`js/components/allocationEditor.js`。

## 滑鼠所在列的標示
兩個總覽頁的時間軸,滑鼠移到某一列時,整列(名稱欄加右邊軌道)的白底會改成淡淡的底色,框線不變(`css/timeline.css` 最後一段,顏色 `#eef5f8`)。

## 專案對話框
客戶欄為可下拉選擇(已有客戶)也可自行輸入的 combobox;專案狀態只顯示英文代碼。

## 顯示模式(專案總覽)
上方「顯示模式」下拉選單:專案里程碑 / 專案里程碑+人力總和 / 專案里程碑+成員細項。雙擊個別專案右邊空白處仍可單獨切換該專案的成員細項(此時選單會暫時顯示「部分專案顯示成員細項」)。

## 拖曳移動可視範圍
兩個總覽頁的時間軸區域,按住滑鼠左鍵拖曳就能上下左右移動可視範圍(游標是手掌)。從按鈕、配置長條、里程碑、欄寬把手等有自己功能的地方開始按不會變成拖曳;移動超過 4px 才算拖曳,所以單擊、雙擊照常運作。程式:`js/components/dragPan.js`。

## 人力資源總覽的排序(僅限管理員)
管理員在搜尋列會多一個「排序」下拉選單與「遞增 / 遞減」(會記住上次的選擇,預設姓名、遞增);viewer 看不到,維持原本的順序(依職務、姓名)。選項:姓名(name)、工號(employee_id)、職級(job_grade → job_title)。遞減時所有排序鍵一起反向;沒填的值(工號、職級、職稱)不論遞增遞減都排最後。邏輯在 `js/utils/memberSort.js`。

## 日期尺度(日 / 週 / 旬 / 月 / 季 / 年)
專案總覽與人力資源總覽的時間軸共用同一套日期尺度,由細到粗:
- **日**:每格 1 天;**週**:每格 1 週(週一到週日);**旬**:每格 1 旬(上旬 1~10 日、中旬 11~20 日、下旬 21 日~月底);**月**、**季**(1~3、4~6、7~9、10~12 月)、**年**。
- 日、週、旬的日期列分兩層:上層顯示年月(捲動時文字會黏在可視範圍左側),下層顯示日 / 週 / 旬。
- **Ctrl + 滑鼠滾輪**(在時間軸上)可切換尺度:往上滾 = 放大(往「日」),往下滾 = 縮小(往「年」);滑鼠指著的日期縮放後會留在原位。邏輯在 `js/components/wheelZoom.js`。
- **休假日標示**:日、週、旬三個尺度會標示休假日——週六、週日自動標示,整欄淡灰底色貫穿所有列(日尺度另外把日期改成紅字);連續的休假日(週六日、春節連假等)合併成一塊。月、季、年預設不標示(一天只有 6 / 2.5 / 不到 1 個像素,週末會變成密集條紋),想標示的話,把 `'month'`、`'quarter'`、`'year'` 加進 `js/utils/constants.js` 的 `HOLIDAY_SHADE_UNITS` 即可。平日的國定假日 / 補假放在同一檔案的 `HOLIDAYS`(已預填 2026、2027 年政府行政機關辦公日曆,總天數與官方公布的 120 / 121 天相符);補班日放在 `MAKEUP_WORKDAYS`。每年新的辦公日曆公布後,請在 `HOLIDAYS` 補上新的一年。假日名稱只在日尺度的日期提示中顯示。另外 `THAI_HOLIDAYS`(同一檔案)放泰國的平日休假日(已填 2026、2027 年,依泰國央行金融機構休假日曆),與台灣休假日合併標示:任一邊放假的日子都標成休假日,底色依種類區分——週六日、台灣假日、兩地同一天放假同為灰色,只有泰國假日是淡淡的紅色(顏色只在 `css/timeline.css` 的 `--hol-gray`、`--hol-th` 兩個變數定義一次,日期欄位與底色共用),日期提示會寫「泰國:名稱」,兩地同一天放假則兩個名稱並列。
- 各尺度每天佔幾個像素在 `js/components/timeAxis.js` 的 `ZOOMS`。

## 縮放時保持畫面位置
縮放(日期尺度按鈕或 Ctrl + 滾輪)後,水平保持滑鼠指著(按鈕縮放則是畫面中央)的日期,垂直保持滑鼠指著(按鈕縮放則是畫面中央)的那一列資料,不會跳回最上面。垂直是記「第幾列 + 列內位置」而不是捲動距離,因為不同尺度下每一列的高度可能不同。邏輯在 `js/components/scrollAnchor.js`。篩選、搜尋改變時列會變動,垂直位置維持回到最上面。

## 左側名稱欄(「專案」/「成員」)的標題與寬度
- 標題格的文字水平、垂直都置中。
- 欄寬可以用滑鼠拖曳調整:拖曳標題格右緣的把手(游標會變成 ↔,滑鼠移上去會出現一條線);**雙擊**把手還原預設寬度(200px);把手取得焦點(Tab)後可用 ← → 微調,Shift 加大幅度。範圍 120px ~ 600px(視窗很窄時會保留至少 240px 給日期軌道)。
- 專案總覽與人力資源總覽的欄寬各自獨立,並記在瀏覽器裡(重新整理仍保留)。預設寬度與下限在 `js/components/timeAxis.js` 的 `LABEL_W`、`MIN_LABEL_W`;拖曳邏輯在 `js/components/columnResize.js`。


## 專案長條編輯(僅管理員,專案總覽)
單擊專案長條的外框(邊緣 5px 內)進入編輯模式:外框閃爍,左右邊界可拖曳調整開始 / 結束日期(上方即時顯示日期)。拖曳只改畫面,旁邊出現「確定 / 取消」,按「確定」才寫入資料庫;再單擊長條、點其他地方或按「取消」都是放棄。因為畫面上的兩端日期可能是由里程碑 / 配置推算出來的,確定時開始、結束日期會一起寫入。程式:`js/components/projectBarEditor.js`。


## 客戶 / 機種篩選(專案總覽)
原本的搜尋框拆成「客戶」「機種」兩個 combobox(`js/components/combobox.js`,自製的,不是瀏覽器內建的 datalist):右邊永遠顯示 ▾,按它或點輸入框展開清單,清單位置與寬度對齊該 combobox;清單第一項「(全部)」= 清除。也可以直接輸入字串,篩選出客戶(或機種)「包含」該字串的專案(不分大小寫);兩欄同時有值時兩個條件都要符合,再與階段勾選一起篩選。兩個清單互相連動:客戶欄有篩選時,機種清單只列出符合的機種,反之亦然。


## 刪除里程碑(僅管理員)
「編輯里程碑」視窗左下角有「刪除」按鈕:第一次按會變成「確定刪除」並提示無法復原,再按一次才真的刪除(寫入資料庫並從時間軸移除)。


## 拖曳移動 popup 視窗
所有 popup 視窗(專案 / 成員 / 人力配置對話框、里程碑新增 / 編輯小視窗)都能按住標題列拖曳移動位置,避免擋住需要看的資訊;標題列不會被拖出畫面,關掉重開回到原位。程式:`js/components/popupDrag.js`。


## 滑鼠位置的縱線與日期
滑鼠在時間軸區域(不含第一列日期列、第一欄名稱欄)移動時,依滑鼠位置畫一條淡淡的 1px 縱線,並在第一列(日期列)顯示該線對應的日期與星期。線不吃滑鼠事件,不影響點擊、拖曳;顏色在 `css/timeline.css` 的 `.tl__cursor`。程式:`js/components/cursorLine.js`。


## 手機直式
專案總覽、人力資源總覽的 viewport 設為 `width=1100`(不指定 initial-scale):手機(直式或橫式)都以 1100px 寬的桌面版面顯示,一開始自動縮放到剛好符合螢幕寬度,可雙指放大後再用手指滑動;登入頁(index.html)維持原本的手機版面。


## 手機橫式的時間軸高度
觸控裝置橫式時(`pointer: coarse` + `orientation: landscape`),時間軸區域高度改成約整個可視高度(`100dvh - 80px`),往下滑動頁面後,整個可視區都是時間軸。電腦瀏覽器不受影響。見 `css/timeline.css` 最後的 media query。


## 手機:兩指橫向縮放
在時間軸本體(不含第一列日期列、第一欄名稱欄)用兩根手指縮放時,依兩指一開始的排列方向決定:接近水平排列 = 橫向縮放,等同 Ctrl + 滾輪(張開 = 放大往「日」,捏合 = 縮小往「年」),兩指水平距離每變化約 25% 切一格,一次手勢可連續切換多級,兩指中央的日期與資料列留在原處;接近垂直排列 = 維持瀏覽器原本的手勢(縮放整個畫面)。第一列、第一欄上的雙指手勢也維持瀏覽器原本的行為。程式在 `js/components/wheelZoom.js`。
